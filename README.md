# nvva.ai

NVVA OS（女娲）官网源文件，托管于 GitHub Pages，域名 nvva.ai。

- `index.html`：单页网站（中文 / English / Русский），首屏动画与鼠标特效均为内联脚本，无构建步骤。
- `hero.jpg`：首屏背景图；`og.jpg`：分享卡片封面。
- `brand/`：Logo、favicon 与 manifest（来自 NVVA_OS_Logo_Kit 暂定版）。
- `CNAME`：自定义域名 nvva.ai。

女娲 OS 的开发代码在另一个私有仓库中，本仓库只包含公开网站。
